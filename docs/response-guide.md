# ICS-SHIELD — Defense & Response Playbook Guide

## Safe Laboratory Playbooks
- `PLAYBOOK-MODBUS-CONTAINMENT`: Simulated network isolation of target PLC.
- `PLAYBOOK-PROCESS-SAFE-STATE`: Forces process variables to safe baseline values.
- `PLAYBOOK-QUARANTINE-DEVICE`: Places asset in quarantine state.
- Execution requires explicit approval (`ADMIN_APPROVAL`). SHA-256 evidence hashes are generated upon completion.
