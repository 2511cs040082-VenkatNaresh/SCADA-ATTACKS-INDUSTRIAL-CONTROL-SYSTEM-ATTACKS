# ICS-SHIELD — WebSocket Real-Time Events Reference

## Real-Time Channel Event Types
- `TELEMETRY_UPDATE`: Continuous process variable reading updates.
- `NETWORK_FLOW`: Network session and protocol flow records.
- `NEW_ALERT`: Correlated security alert broadcasts.
- `DETECTION_ALERT`: Rule, Behavioral, or ML detection notifications.
- `INCIDENT_UPDATE`: Incident state transition and timeline updates.
- `SIMULATION_PROGRESS`: Active laboratory simulation step events.
- `SYSTEM_STATUS`: Platform component health state notifications.
