# ICS-SHIELD — User Guide

## 1. Navigating the SOC Interface
- **Dashboard** (`/dashboard`): High-level operational metrics, active threats, real-time alert feed, system health status.
- **Asset Intelligence** (`/assets`): Asset discovery, inventory, health score monitoring, and criticality risk weighting.
- **Network & Protocol Monitor** (`/network`, `/protocols`): Real-time Modbus TCP packet inspection, session tracking, and flow pair visualization.
- **Process Telemetry** (`/process`): Live trend charts for water tank levels, flow rates, pressure, and temperature.
- **Alerts & Incidents** (`/alerts`, `/incidents`): Correlated alert queues and incident case workspaces.
- **MITRE ATT&CK for ICS** (`/mitre`): Interactive v14 matrix browser and technique mapping matrix.
- **Defense & Response** (`/response`): Automated playbooks, recommendation reviews, and approval workflows.
- **Attack Simulation Lab** (`/simulation`): Preflight scenario launcher, live story mode (`/simulation/story/:runId`), and Evaluation Matrix summary.
- **Reports & Analytics** (`/reports`, `/analytics`): 16 report categories, PDF/CSV exporters, and multi-domain analytics.
- **Administration** (`/admin`, `/settings`): User/role management, category configuration, and audit logs.
