# ICS-SHIELD Laboratory & Simulation Environment

## Overview
The `ics-lab` directory houses the topology specifications, virtual PLC simulators (e.g. Conpot / OpenPLC / Modbus server instances), and Purdue Model network configuration files.

## Safety Guidelines
> [!IMPORTANT]
> The laboratory simulation environment is strictly isolated from production physical networks. All simulated control loops run on internal Docker subnets (192.168.1.0/24).
