# ICS-SHIELD Accessibility & Design System Guidelines

## 1. Accessibility Features
- **Keyboard Navigation**: Full `Tab`, `Arrow`, `Enter`, and `Escape` key navigation across modal dialogs, global search (`Cmd+K`), navigation links, and forms.
- **ARIA Attributes**: Proper use of `aria-label`, `aria-expanded`, `aria-hidden`, and `role="navigation"`.
- **Visible Focus States**: High-contrast outline focus rings on interactive buttons and input fields.
- **Color Contrast & Indicators**: Color is never the sole indicator of severity; all badges include text labels (e.g. `🔴 HIGH`, `🟢 ONLINE`, `🟡 LAB`).

---

## 2. Responsive Layout Rules
- **Desktop**: Full multi-column SOC layout with persistent left directory and top navigation header.
- **Tablet**: Responsive grid collapse with scrollable component views.
- **Mobile**: Stacked single-column layouts with touch-friendly tap targets.
