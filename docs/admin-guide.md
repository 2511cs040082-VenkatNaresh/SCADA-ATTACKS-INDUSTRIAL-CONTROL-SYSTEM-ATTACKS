# ICS-SHIELD — Administration & Configuration Guide

## Admin Center Overview (`/admin`)
- **User & RBAC Management**: Manage users, assign roles (`ADMIN`, `SECURITY_ANALYST`, `SOC_OPERATOR`, `OT_OPERATOR`, `VIEWER`), and modify permission policies.
- **Session Control**: Inspect active user sessions and revoke compromised tokens.
- **Category Configuration Settings**: Configure thresholds for Security, Telemetry, Detection, Behavioral Z-scores, ML Models, Alerts, Incidents, MITRE, Response, Simulation, Reports, Retention, Logging, WebSocket, and Performance.
- **Audit Logs**: Immutable transaction log viewer displaying actor, action, resource, result, and SHA-256 hash signatures.
